## Welcome to Pollinate

Pollinate is a flexible supply chain SaaS platform that enables rapid implementation of software solutions for manufacturing and distribution companies. Our core application acts as a flexible data lake, allowing coding agents to build apps and integrations that seamlessly connect to existing supply chain systems.

## About This API

The Pollinate External API provides programmatic access to your supply chain data. Use this API to:

- Integrate with ERPs, MRPs, and other supply chain software
- Build custom dashboards and applications
- Automate workflows and processes
- Sync data between systems in real-time

## Key Features

- **RESTful Design**: Standard HTTP methods and status codes
- **Nested Resources**: Handle variants, lines, locations, and contacts within main resources
- **Intelligent Patching**: Update nested resources with automatic diffing logic
- **Pagination**: Efficiently paginate through large datasets
- **Organization Scoped**: All requests are scoped to your organization
